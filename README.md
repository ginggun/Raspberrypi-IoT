
# Raspberry Pi IoT Project

## Overview
Computer Systems Lab project using Raspberry Pi,
AWS IoT Core, MQTT, and Python.

## Technologies
- Raspberry Pi
- AWS IoT Core
- MQTT
- TinyDB
- Python
- Qwen SLM
- Discord Webhook

## Project Features
- Sensor data collection
- MQTT communication
- Threshold-based monitoring
- Automated Discord notifications

## Status
Work in progress.
